# CRAS – Continuous Work Activity Tracker

A lightweight background agent that continuously tracks your work activity, generates a human-readable daily log, and automatically syncs it to Google Drive.

**Privacy-first** • **Zero manual intervention** • **Windows focused**

---

## Features

- Active window / application tracking
- Browser tab & URL tracking (via Chrome/Edge extension)
- Mouse click and keyboard activity frequency (for idle detection)
- Idle vs Active detection
- Daily Markdown log with:
  - Rolling summary
  - Detailed timeline
- Automatic upload to Google Drive using rclone
- Pause / Resume with hotkey (`Ctrl + Alt + P`)
- Starts automatically on system boot
- Fully configurable via `config.yaml`
